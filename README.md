# Bookstore Management System

A command-line bookstore management system built with Python and SQLite. The program lets users add, update, delete, and search for books, as well as view full details across the book and author database, all through a simple menu-driven interface.

## Setup
Run `bookstore_management_system.py` directly. The database (ebookstore.db) is created automatically on first run, pre-populated with sample book and author data.

## Tools
Python, SQLite
